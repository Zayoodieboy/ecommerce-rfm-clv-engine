# ecommerce-rfm-clv-engine
End-to-end SQL data project calculating Customer Lifetime Value (CLV) and RFM behavioral segmentation for an e-commerce brand to optimize marketing retention budgets.


Company: A mid-sized global e-commerce apparel and lifestyle brand.

The Problem: The marketing team is running broad acquisition campaigns with a fixed budget. However, they are treating a one-time buyer who spent $20 the exact same way as a repeat VIP customer who has spent $1,200 over the past year.

The Objective: Write an end-to-end SQL script that ingests raw transaction data, calculates Recency, Frequency, and Monetary (RFM) scores, segments customers into actionable marketing tiers (Champions, At-Risk, Lost), and calculates historical Customer Lifetime Value (CLV) by acquisition channel.
